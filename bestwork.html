Best Work

This page showcases a project that represents my best work and creativity in computer science.

U3L14 Mini-Project: Animation

My animation is called Snowball Fight. It shows two kids outside in the snow while one kid throws a snowball and the other kid gets hit. The animation includes a snowy background and four sprites: the background, the kid throwing, the kid walking, and the snowball.

The snowball moves across the screen using a counter pattern, and it also moves slightly up and down randomly to make the animation look more realistic. When the snowball touches the other kid, the character spins and moves off the screen. I also added text such as the title, a score that continuously increases, and “ouch!” when the kid gets hit.

I think this project is an example of my best work because I put a lot of effort and creativity into it. I am proud of how the animation actually feels alive and tells a small story instead of just having objects move randomly across the screen.

The moving snowball, spinning character, and changing score all make the animation more interactive and fun to watch. I also liked being able to add my own ideas and make the project more creative than the basic requirements.

This project was a little difficult because I had to figure out how to make different sprites interact with each other and how to use variables and counter patterns correctly. Sometimes the movement or collisions did not work the way I wanted, so I had to test and fix my code many times.

Even though it was challenging, I enjoyed working on the project because I liked seeing everything slowly come together in the end. It felt rewarding once the animation finally worked the way I imagined it.

While creating this project, I used many coding concepts and skills including sprites, variables, conditionals, random movement,counter patterns, and the draw loop. I also learned how to make animations smoother and more realistic.

Overall, this project stands out to me because it shows both my creativity and my improvement in coding. It is one of the projects I feel most proud of from this class.
